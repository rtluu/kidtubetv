# KidTubeTV

A YouTube Kids-style app for watching classic 90s & 00s kids shows. Built with React Native + Expo for web, iOS, and Android.

## Getting Started

```bash
npm install
npx expo start --web
```

## Tech Stack

- **Framework:** React Native + Expo (SDK 54)
- **Routing:** Expo Router (file-based)
- **State:** Zustand + TanStack React Query
- **Video:** YouTube iframe embeds + direct video support
- **Backend:** Firebase (Firestore + Analytics) — Phase 6
